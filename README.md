# VANTA Tools

A multi-tool web app — TempMail, Discord OSINT, Domain OSINT, Username lookup, IP Lookup.

## Features

- 📧 **TempMail** — instant disposable inbox, live refresh, read messages
- 🎮 **Discord OSINT** — ID lookup, avatar, banner, badges, account creation date
- 🌐 **Domain OSINT** — IP, registrar, ISP, geo, recon links
- 👤 **Username OSINT** — 18 platforms + automated scan link
- 📡 **IP Lookup** — full geo, ASN, ISP, Shodan/AbuseIPDB

## Stack

- Pure HTML/CSS/JS — zero dependencies
- All free APIs, no keys required

## Deploy

Drop `index.html` anywhere:
- Base44
- Netlify (drag and drop)
- Vercel
- Any static host

## APIs Used

| Feature | API | Cost |
|---|---|---|
| TempMail | mail.tm | Free, no key |
| Discord | japi.rest | Free, no key |
| Domain/IP | ipapi.co | Free tier |
| Domain WHOIS | whoisjson.com | Free tier |
| Username | direct platform links | Free |
